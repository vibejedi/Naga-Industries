# Web Interface Guidelines (Vercel), pinned copy

Read `rules.md` in this folder and review the named files against it. Report findings grouped by file as
`file:line - finding`, as `rules.md` describes.

This is a pinned copy of `command.md` from vercel-labs/web-interface-guidelines (MIT), commit `434b7f9`,
copied 18 November 2026. Vercel's own skill downloads the rules from GitHub on every run; this copy does not,
so the rules cannot change without a commit here. To update, copy the new `command.md` over `rules.md` and
change the commit above.

Where a rule and the Naga design system disagree, the Naga system wins. Known differences: Naga headings are
sentence case (the guidelines ask for Title Case), and Naga copy says "we" (the guidelines avoid first person).
